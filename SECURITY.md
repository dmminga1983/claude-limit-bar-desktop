# Security policy / Безопасность

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** (Security tab, "Report a vulnerability"). Do not open a public issue for security problems.

## Changes to this repository

Only the owner can change this repository. Every change to `main` requires the code owner's approval (see `.github/CODEOWNERS`).

---

## Как сообщить об уязвимости

Используйте **приватное сообщение об уязвимости** на GitHub (вкладка Security, «Report a vulnerability»). Не открывайте публичный issue по вопросам безопасности.

## Изменения в репозитории

Менять репозиторий может только владелец. Любое изменение в `main` требует одобрения владельца кода (см. `.github/CODEOWNERS`).
