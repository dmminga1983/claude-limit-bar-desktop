# Claude Limit Bar — приложение для Windows

**Видите остаток лимита Claude заранее — и больше не упираетесь в него посреди задачи.** Та же идея, что у расширения для браузера, но в виде отдельной программы для **Windows 10/11**, которая работает даже с закрытым браузером. Стеклянная карточка поверх окон (glassmorphism / Liquid Glass), цветной значок в трее и выбор, где показывать.

Читает те же самые цифры расхода, которые и так видит ваш аккаунт, рисует их у вас на компьютере и обращается только к claude.ai — без регистрации, без сервера, без слежки и телеметрии. Бесплатно, открытый код (MIT).

[English version →](README.md)

Нужно просто в браузере? Смотрите [claude-limit-bar-extension](https://github.com/dmminga1983/claude-limit-bar-extension) (Chrome и браузеры на Chromium).

> **Вставили эту ссылку в обычный чат Claude (claude.ai) и написали «установи»?** Оттуда это не сработает: обычный чат умеет только читать файлы, которые вы прикрепили, доступа к терминалу вашего компьютера у него нет. Нужен **Claude Code** (его можно попробовать бесплатно, он входит в подписку Claude). Как быстро перейти:
>
> 1. Откройте PowerShell и установите его (пропустите, если уже есть):
>    ```powershell
>    irm https://claude.ai/install.ps1 | iex
>    ```
>    (или через WinGet: `winget install Anthropic.ClaudeCode`)
> 2. Откройте терминал и запустите `claude`, чтобы начать сессию.
> 3. Вставьте в эту сессию блок из раздела **«Установка через Claude Code»** ниже — остальное он сделает сам.
>
> Полная инструкция по установке, если что-то из этого не сработало: https://code.claude.com/docs/en/quickstart

Есть два способа отображения, **каждый включается и выключается отдельно**:

1. **Значок в трее** — значок с полоской остатка лимита (зелёный → жёлтый → красный, по худшему из двух окон — 5-часового и недельного); при наведении подсказка с процентами и временем до сброса.
2. **Плавающее окно** — небольшая стеклянная карточка (настоящее размытие фона через Windows Acrylic, а если система его не поддерживает — аккуратный нарисованный «стеклянный» вид). Показывает обе полоски с цветом и процентами — крупно и читаемо. Левой кнопкой мыши перетаскивается (позиция запоминается), правой — открывает меню. Если отпустить окно рядом с краем или углом экрана (ближе ~24 px), оно к нему прилипает.

У плавающего окна два режима видимости (подменю «Показывать» в меню по правой кнопке или значок в трее → «Показывать окно»):

- **Всегда поверх окон** — обычное окно поверх всех, видно что бы ни было открыто.
- **Только при работе с Claude** — окно появляется, только когда на переднем плане приложение Claude или вкладка claude.ai в браузере, в остальное время скрыто.

Оба переключателя доступны из обоих мест:

- правая кнопка по значку в трее → «Плавающее окно» (галочка), «Показывать окно» (подменю с двумя режимами выше);
- правая кнопка по плавающему окну → «Скрыть окно», «Значок в трее» (галочка), «Показывать» (то же подменю), «Выход».

Хотя бы один способ отображения (трей или окно) всегда остаётся включённым: если выключить последний, второй включится автоматически — иначе приложением было бы невозможно управлять.

## Откуда берутся данные

Приложение не трогает и не расшифровывает cookie браузера. При первом запуске оно открывает собственное окно входа в claude.ai, один раз сохраняет сессию и дальше работает само: от имени этой сессии обращается к тому же внутреннему адресу `/api/organizations/.../usage`, что и расширение. С вашего компьютера ничего не уходит, кроме запросов к самому claude.ai. Опрос лимита — это чтение вашего собственного статуса, как в интерфейсе сайта: сообщения он не тратит и в лимит не засчитывается.

> Вход через «Continue with Google» во встроенном окне может заблокировать сам Google (он отказывается работать во встроенных браузерах). В этом случае войдите по адресу почты и паролю или коду.

## Установка через Claude Code (проще всего)

Если на компьютере уже есть [Claude Code](https://claude.com/claude-code), руками ничего делать не нужно: скопируйте весь блок ниже и отправьте его в Claude Code (не в обычный чат claude.ai — у него нет доступа к терминалу). У Claude Code есть настоящий доступ к терминалу на этом компьютере, поэтому он сам проверит Python, склонирует репозиторий, установит зависимости, прогонит тесты и запустит приложение. Спрашивать вас он будет, только если наткнётся на реальную проблему (например, Python не установлен).

```
Установи мне приложение Claude Limit Bar для Windows — это индикатор
остатка лимита Claude.ai (значок в трее + плавающее окно).

Репозиторий: https://github.com/dmminga1983/claude-limit-bar-desktop

Сделай по порядку:
1. Проверь, что есть git и python (версия 3.10+; запуск `python` НЕ должен
   открывать Microsoft Store — если открывает, это заглушка магазина,
   а не настоящий Python; предупреди меня и остановись, сам ничего
   не устанавливай).
2. Склонируй репозиторий в C:\Users\<моё_имя_пользователя>\Documents\ClaudeLimitBar —
   если папка с таким именем уже есть и это не git-репозиторий, спроси
   меня, можно ли её заменить, ничего не удаляй молча.
3. В этой папке создай виртуальное окружение (.venv) и установи
   зависимости из requirements.txt.
4. Прогони тесты (pytest) — если что-то упало, покажи, что именно,
   и не продолжай молча.
5. Запусти приложение (python -m app.main) в фоне и добавь его
   в автозагрузку Windows (ярлык в «Автозагрузке»), чтобы оно само
   запускалось при входе — как описано в README.md этого репозитория
   (там есть install.bat, который делает всё это; можешь просто
   запустить его вместо ручных шагов).
6. В конце коротко напиши, что получилось и что мне ещё нужно сделать
   руками (например, один раз войти в claude.ai во всплывающем окне).
```

После этого при первом запуске откроется окно входа в claude.ai — войдите один раз вручную, как в обычном браузере. Это просит само приложение, Claude Code к этому шагу отношения не имеет — он только запускает программу.

> Речь не об обычном чате claude.ai — оттуда Claude ничего не может установить на ваш компьютер, он только читает прикреплённые файлы. Нужен именно Claude Code (ставится отдельно, у него есть терминал).

## Ручная установка на Windows 10/11

Нужен **настоящий Python 3.12** с [python.org](https://www.python.org/downloads/) (при установке отметьте «Add python.exe to PATH») и среда Microsoft Edge WebView2 (на Windows 10/11 обычно уже есть).

> Внимание: если команда `python` в терминале открывает Microsoft Store или молча ничего не делает — это не Python, а заглушка «псевдонимов выполнения приложений» из магазина. Установите Python с python.org (или отключите заглушку: Параметры → Приложения → Псевдонимы выполнения приложений → выключите «python.exe»).

Скачайте репозиторий (**Code → Download ZIP** на странице проекта на GitHub или `git clone`) и просто **дважды щёлкните `install.bat`**. Он создаст виртуальное окружение, установит зависимости, прогонит тесты, добавит приложение в автозагрузку и запустит его — подробности и ошибки окажутся в `install_log.txt` рядом.

То же самое вручную:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

При первом запуске откроется окно входа в claude.ai — войдите как обычно. После входа окно спрячется, и появятся значок в трее и/или плавающее окно.

### Обычный запуск и отладка

После установки приложение уже добавлено в автозагрузку Windows и запускается само, вообще без видимых окон. Запустить вручную можно двумя способами:

- **`start_silent.bat`** — обычный способ. Запускает приложение через `pythonw.exe`: никакого окна консоли, ничего не мешает. Закрывать или сворачивать нечего — приложение просто работает в фоне, видны только значок в трее и/или плавающее окно.
- **`debug_console.bat`** — только для отладки. Запускает через обычный `python.exe` в видимом окне консоли, чтобы были видны ошибки и трассировки. **Если закрыть это окно, закроется всё приложение** — так и задумано, для каждодневной работы этот режим не предназначен.

Если вы видите окно консоли и при его закрытии всё пропадает — значит, приложение запущено через `debug_console.bat`. Используйте `start_silent.bat`.

### Сборка в один .exe (по желанию)

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --name ClaudeLimitBar -p . app\main.py
```

Файл появится в `dist\ClaudeLimitBar.exe`.

## Настройки

Хранятся в JSON: `%APPDATA%\ClaudeLimitBar\config.json`.

| Ключ              | Что означает                                                                 |
| ----------------- | ----------------------------------------------------------------------------- |
| `tray_enabled`     | показывать ли значок в трее                                                 |
| `overlay_enabled`  | показывать ли плавающее окно                                                |
| `overlay_mode`     | `always` (всегда поверх) или `claude_only` (только при работе с Claude)     |
| `overlay_x/y`      | последняя позиция окна (запоминается сама, с прилипанием к краям)           |
| `poll_seconds`     | как часто опрашивать лимит (минимум 15, по умолчанию 60)                    |

## Тесты

Логика полосок, переключатели, клиент (на поддельном окне webview), настройки, прилипание окна к краям и режим видимости не зависят от графических библиотек:

```bash
pip install pytest
pytest
```

## Ограничения

- Связка webview + трей + Tk проверена по частям (логика и отрисовка значка — тестами, настоящие окна — вживую на Windows автора), поэтому при первом запуске на новом компьютере возможны мелкие шероховатости: в этом случае пришлите `install_log.txt`/`trace.log` или текст ошибки.
- Режим «Только при работе с Claude» определяет активное окно по заголовку (ищет слово «Claude») — это работает и для приложения, и для вкладки браузера, но в редких случаях (нестандартный заголовок вкладки) может сработать не сразу.
- Только Windows 10/11; macOS и Linux не поддерживаются.
